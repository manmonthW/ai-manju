# AI 漫剧生产术语与权威边界

## 核心实体

- Project：一个剧集、Pilot 或有边界的制作容器。
- Episode：有目标时长的叙事单元。
- Scene：具有固定地点、参与者、目标和退出状态的戏剧单元。
- Shot：稳定的编辑单元，包含起点、一个主要转变和终点。
- Asset：人物、场景、道具、视觉风格或状态的版本化记录。
- Reference：有来源、角色范围和哈希的可读媒体文件。
- Prompt IR：与供应商无关的场景、人物、动作、镜头、参考和限制描述。
- Generation Job：一次有边界、单模态、带审批哈希和状态的生成请求。
- Generated Asset：已经取回并通过媒体结构验证的文件，但不代表创意合格。
- Accepted Asset：通过技术、连续性、叙事和编辑 QA 的生成文件。
- Continuity Lock：对身份、服装、道具、空间、轴线、光向或动作接续的锁定。

## 权威划分

- 剧本 Markdown：拥有戏剧意图与对白。
- 资产圣经：拥有角色身份、服装、场景和道具的连续性事实。
- 分镜合同：拥有 Shot ID、时长、起止边界和禁用项。
- 任务账本：拥有付费生成意图、审批、供应商 ID、成本和状态。
- Manifest：拥有一个已批准或豁免资产的实际事实和下游限制。
- Lovart：拥有实时模型、实时参数、实时价格、账户余额及生成媒体字节。
- QA：拥有通过、拒绝与豁免事实；技术成功不能自动变成创意通过。
